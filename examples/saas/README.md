# Example: SaaS landing

`before.html` is a typical noisy marketing page.

`after-light.html` and `after-dark.html` are the Quiet rebuild as Cascade, an issue tracker. They use a 1104px container on structural rails, a two-line hero with a two-tone headline, the real product inside a bezel within the fold, features as grid cells, one testimonial with metrics, and a single primary CTA grammar.

Folds (`-fold`), scrolled sections (`-s1`, `-s2`) and mobile (`-mobile`) ship at 2x.
