# Example: Changelog

Cascade changelog on the grid. Each entry has a date and version column, and the lead entry shows the real UI it changed. It includes an email field for updates. `article.html` is a single changelog post.

\`article.html\` is a single entry: a 672px article with an On this page list, a meta row, the product in a bezel, and three more entries. Screenshots: \`article-fold.png\`, \`article-s1.png\`, \`article-mobile.png\`.
