Webhooks

Get a signed HTTPS request every time an issue, comment, or cycle changes in your workspace.

Create an endpoint

Go to Settings → API → Webhooks, or create one with the API. Trestle sends a test event right away so you can confirm your handler responds with a 2xx.

curlNodePython
curl https://api.trestle.app/v1/webhooks \
  -H "Authorization: Bearer $TRESTLE_KEY" \
  -d url=https://hooks.northwind.co/trestle \
  -d "events[]=issue.updated" -d "events[]=comment.created"

Verify the signature

Every request carries a Trestle-Signature header. Compute an HMAC-SHA256 of the raw body with your signing secret and compare it in constant time.

Reject anything older than five minutes. The signed timestamp protects you from replayed requests.

Retries

  1. Trestle retries non-2xx responses with backoff for up to 24 hours.
  2. After 50 consecutive failures the endpoint is paused and admins get an email.
  3. Replay any delivery from the log in the dashboard.
