Getting started

Install the SDK, create a client, and make your first request. About five minutes if you already have an API key.

Install

npm install @orbit/sdk

Also available for Python and Go.

Create a client

import { Orbit } from '@orbit/sdk'

const client = new Orbit({
  apiKey: process.env.ORBIT_KEY,
})

List issues

const issues = await client.issues.list({
  team: 'ENG',
  status: 'started',
})
