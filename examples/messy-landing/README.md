# Example: messy landing → Quiet

`before.html` is deliberately loud: purple gradient, glass nav, eyebrow pill, mismatched buttons, emoji feature cards, monospace step cosplay, stock AI copy.

`after.html` is the same product — NovaBoard — restyled under Quiet: near-monochrome tokens, Inter + Newsreader, 4px spacing, concentric radii, action-named buttons, no decorative motion.

Screenshots (`before.png`, `after-light.png`, `after-dark.png`) are rendered at 2× from headless Chrome.
