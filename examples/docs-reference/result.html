job.rescheduled

Sent when a job moves to a new crew, day or arrival window, whether a dispatcher dragged it or the board reshuffled after a delay.

Payload

Each delivery is a POST with a JSON body. The previous and current objects let you diff the change without fetching the job again.

job.rescheduled.json
{
  "id": "evt_8Kq2fW1",
  "type": "job.rescheduled",
  "created": "2026-10-15T15:41:07Z",
  "reason": "auto_reshuffle",
  "job": { "id": "job_31907", "address": "87 Pine Ct, Denver, CO" },
  "previous": { "crew": "crew_4", "window": ["09:00", "10:00"] },
  "current":  { "crew": "crew_4", "window": ["09:20", "10:20"] }
}

Fields

reasonstringOne of dispatcher, auto_reshuffle or customer_request.
previous.windowarrayArrival window before the change, in the job's time zone.
current.crewstringCrew now assigned. Equal to previous.crew when only the time moved.
Customers are texted by Pinecrest before this event is sent. Do not send your own message unless you turned off arrival texts in Settings → Notifications.

Retries

Return any 2xx within 10 seconds. Failed deliveries retry 8 times over 24 hours with exponential backoff, then show as failed in the dashboard.
