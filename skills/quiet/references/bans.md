# Bans

Absolute. Treat as fail conditions in critique.

## AI slop

- Purple / indigo gradients and glow CTAs
- Glassmorphism / backdrop-blur panels as decoration
- Emoji used as icons or bullets
- Three identical icon-topped feature cards
- Soft grey drop-shadow soup under every card
- Gradient text fills
- Decorative blobs, fake dashboards of grey bars

## Gallery cosplay

- Monospace micro-labels / mono as fake “technical” voice (real code blocks OK)
- Index cosplay: `01 / 02 / 03`, `(001)`, “Step 02” markers
- Hairline grids, crop marks, crosshairs, design-tool chrome as ornament
- Tiny tracked uppercase labels scattered as ornament
- Corner version stamps (`UI skill · v1`, local time, coordinates, “© scroll”)

## Minimal-template slop (Quiet-specific)

These look “clean” but are not the north star (Rauno / Paco / Emil / DD):

- **Big-serif-on-beige** marketing posters (Newsreader hero on warm paper)
- **Warm-craft SaaS** (“artisan” product sites): cream or paper grounds + serif display + terracotta/earthy accents, often with colored avatar dots as decoration
- **Stat cards** as the hero (“Active boards · 128”)
- **Hairline row tables** (label | description rows separated by rules) as a fake feature section
- **Serif section heads + grotesk body** SaaS rhythm on product/marketing pages by default
- **Em dashes** in UI copy and README prose (use commas, periods, or parentheses)
- Decorative divider lines used to prop up thin content (including a line above a chat composer when the composer already has its own border)
- Tagline pairs flanking a rule (“Interaction detail first / Ornament never”)
- Colored logo squares / brand marks in app sidebars (text wordmark only; keep alignment with nav)
- Brand names that collide with existing AI models or famous products (e.g. Muse). Invent neutral names.
- Empty half-screens in app UI (bottom or trailing column left blank). Fill with real content or size the layout the way real apps do.
- Buttons that float mid-container instead of aligning to the layout grid
- Generic paid CTAs (“Start”) for paid plans. Prefer “Start trial”, “Get Pro”, “Get Business” with price context
- SVG / AI product silhouettes on e-commerce when a real photo is expected; no inventory-code captions overlaid on product images

## Quiet craft bans

- Decorative motion (see `motion.md`)
- Unrequested features
- Duplicate parallel components for the same job
- Raw hex / ad-hoc color sprawl outside tokens
- Resting shadows and glows on static surfaces
- Centered dense app layouts
- Animating high-frequency or keyboard actions

Removing a ban is not enough. Fill with real content, a working UI fragment, type, and space. Do not replace one tell with another.
