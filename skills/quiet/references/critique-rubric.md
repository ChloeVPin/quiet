# Critique rubric

Run after every pass. Judge the rendered UI, not the intent in the code.

## Gate (any fail = not done)

| # | Check |
| --- | --- |
| 1 | Stranger still recognizes the product / site |
| 2 | Zero items from `bans.md` |
| 3 | Near-monochrome; ≤1 accent; no gradients |
| 4 | Type pairing + ~65ch measure + balance/pretty + tabular nums where needed |
| 5 | 4px spacing + concentric radii (or documented optical nudge) |
| 6 | Product motion ≤300ms ease-out interruptible; none on high-frequency/keyboard |
| 7 | `prefers-reduced-motion` respected |
| 8 | Buttons name actions; no eyebrow kickers; no stock AI phrases |
| 9 | No unrequested features; no duplicate primitives; colors via tokens |
| 10 | Could sit next to rauno.me without embarrassment |

## Score each 1–5 (optional)

Recognition · Restraint · Type · Space · Motion · Detail · Copy

Fix the lowest two before declaring the pass complete. One re-check maximum unless the user asks for more.
